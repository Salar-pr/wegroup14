# قرارداد فنی مدرسه‌یار

این پروژه یک نمونه UI/UX است. قرار نیست API، پایگاه داده، احراز هویت واقعی یا درگاه پرداخت به آن اضافه شود. داده‌ها در `src/data/` تعریف شده‌اند و `AppProvider` هنگام شروع برنامه یک نسخه تازه از آنها می‌سازد. هیچ بخشی نباید برای داده برنامه از `localStorage`، `sessionStorage`، کوکی یا سرویس بیرونی استفاده کند.

## نقش‌ها و مسیرها

| پایه مسیر | وضعیت |
| --- | --- |
| `/login` | انتخاب نقش و حساب نمونه، بدون ورود واقعی |
| `/admin/*` | پنل مدیر، با بارگذاری جداگانه |
| `/student/*` | پنل دانش‌آموز، با بارگذاری جداگانه |
| `/parent/*` | پنل اولیا، با بارگذاری جداگانه |
| `/teacher/*` | فقط قالب و صفحه موقت؛ پنل این نقش هنوز آماده نیست |

`RequireRole` از نمایش صفحات یک نقش در حساب نقش دیگر جلوگیری می‌کند؛ این کنترل فقط در رابط کاربری است و جایگزین امنیت سمت سرور نیست. مسیرهای هر نقش در `src/app/router.tsx` و داخل `src/features/<role>/` تعریف شده‌اند. لینک‌های منو در `src/constants/navigation.ts` هستند. سه صفحه مدیر (حقوق، گزارش، برنامه) هنوز موقت‌اند.

## داده و تعامل

- `useData()` مجموعه `db` و تابع `updateEntity` را می‌دهد. نمرات، حضور، پیام‌ها، شهریه، دانش‌آموزان، خانواده‌ها، معلمان، کلاس‌ها و برنامه از همین جا خوانده می‌شوند.
- `useAuth()` حساب انتخاب‌شده را فقط در حافظه نگه می‌دارد. `useToast()` پیام موفقیت یا خطا را نشان می‌دهد.
- شناسه‌های `studentIds` در حساب اولیا باید در `db.students` وجود داشته باشند؛ نمره‌ها و حضور هم باید به دانش‌آموز، کلاس و درس معتبر اشاره کنند. تست `tools/integration-smoke.mjs` این رابطه‌ها را بررسی می‌کند.
- تاریخ ذخیره‌شده ISO است و برای نمایش از کمک‌تابع‌های شمسی در `src/utils/` استفاده می‌شود. نمره از ۲۰ و مبلغ به تومان است.
- ارسال پیام، ثبت نمره و تغییر حضور در همین نشست روی داده مشترک اعمال می‌شود. بازخوانی صفحه یا شروع نشست تازه، نمونه اولیه را برمی‌گرداند.

## رابط کاربری

همه صفحه‌ها فارسی و راست‌به‌چپ‌اند (`lang="fa"` و `dir="rtl"`). برای دکمه، جدول، فرم، نشان وضعیت و کارت آمار از `src/components/` استفاده کنید. رنگ‌ها و فاصله‌ها در تنظیمات Tailwind و `src/styles/` تعریف شده‌اند. قبل از افزودن صفحه، مسیر و دسترسی آن را با منوی همان نقش مقایسه کنید.

```bash
npm run build
npm run lint
npx playwright install chromium
npm run test:smoke
```
