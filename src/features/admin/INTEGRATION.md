# پنل مدیر

`AdminApp` در روتر اصلی زیر `/admin/*` بارگذاری می‌شود. همه صفحه‌ها از `useData()` و داده‌های مشترک `src/data/` استفاده می‌کنند؛ فرم‌ها فقط حافظه همین نشست را تغییر می‌دهند.

صفحه‌های فعال: پیشخوان، دانش‌آموزان، معلمان، کلاس‌ها، حضور و غیاب، نمرات، تکالیف، اطلاعیه‌ها، شهریه (`/admin/payments`)، خانواده‌ها، پیام‌ها و تنظیمات. `/admin/finance` به مسیر شهریه هدایت می‌شود.

صفحه‌های `/admin/payroll`، `/admin/reports` و `/admin/schedule` هنوز طرح نهایی ندارند و پیام توضیحی نشان می‌دهند. پیش‌نمایش جداگانه قدیمی حذف شد؛ همان `npm run dev` برای دیدن نسخه اصلی کافی است.
