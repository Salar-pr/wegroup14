# مدرسه‌یار

نمونه رابط کاربری مدیریت مدرسه برای مدیر، دانش‌آموز و اولیا. پروژه فقط فرانت‌اند است: ورود، پیام‌ها، نمره‌ها و پرداخت‌ها نمایشی‌اند و هیچ داده‌ای به سرور نمی‌رود. تغییرات تا زمانی که صفحه را بازخوانی نکرده‌اید در حافظه مرورگر می‌مانند.

## اجرا

Node.js نسخه ۲۰ یا جدیدتر لازم است.

```bash
npm ci
npm run dev
```

سپس `http://localhost:5173` را باز کنید. برای خروجی نهایی `npm run build` و برای بررسی کد `npm run lint` را اجرا کنید.

## حساب‌های نمونه

در صفحه ورود نقش و سپس سناریو را انتخاب کنید؛ دکمه «ورود با حساب نمایشی» نیازی به تایپ کردن ندارد.

| نقش | نام | ایمیل | رمز | وضعیت نمونه |
| --- | --- | --- | --- | --- |
| مدیر | امیر قاسمی | `admin@school.ir` | `admin123` | مدیریت پرونده‌ها، نمرات و پیام‌ها |
| دانش‌آموز | سارا محمدی | `student@school.ir` | `student123` | نمرات خوب و حضور منظم |
| دانش‌آموز | بردیا هاشمی | `bardia@school.ir` | `student123` | نمره پایین و غیبت نیازمند پیگیری |
| دانش‌آموز | علی محمدی | `ali.m@school.ir` | `student123` | فرزند دوم خانواده محمدی |
| ولی | زهرا کریمی | `parent@school.ir` | `parent123` | دو فرزند و امکان جابه‌جایی بین آنها |
| ولی | حسن رضایی | `h.rezaei@school.ir` | `parent123` | شهریه پرداخت‌شده |
| ولی | فاطمه حسینی | `f.hosseini@school.ir` | `parent123` | شهریه معوق و پیام پیگیری |

حساب `teacher@school.ir` با رمز `teacher123` هم در نسخه نمایشی هست، اما داشبورد معلم هنوز طراحی نشده و فقط صفحه موقت دارد.

داده‌های مشترک در `src/data/` قرار دارند. مدیر، دانش‌آموز و ولی یک مجموعه رکورد را می‌خوانند؛ مثلاً ویرایش یک نمره یا ارسال پیام در همان نشست برای نقش دیگر هم دیده می‌شود. بازخوانی صفحه همه تغییرات و نشست را پاک می‌کند. در این پروژه دیتابیس، API، احراز هویت واقعی یا پرداخت واقعی وجود ندارد.

## مسیرها و تست

- `/admin`: دانش‌آموزان، خانواده‌ها، معلمان، کلاس‌ها، نمرات، حضور، تکالیف، شهریه، پیام‌ها، اطلاعیه‌ها و تنظیمات.
- `/student`: پیشخوان، برنامه، نمرات، حضور، تکالیف، کارنامه، پیام‌ها، اطلاعیه‌ها و پروفایل.
- `/parent`: پیشخوان، فرزندان، نمرات و مقایسه، حضور، تکالیف، شهریه، پیام‌ها و برنامه.

برای تست مرورگر، Chromium مربوط به Playwright را یک بار نصب کنید:

```bash
npx playwright install chromium
npm run test:smoke
```

تست مفصل‌تر اولیا با سرور روشن: `node src/features/parent/tests/e2e.mjs`. تصاویر تست در `artifacts/` ساخته می‌شوند و جزو سورس نیستند.

بخش‌های حقوق، گزارش‌های پیشرفته و برنامه مدیر هنوز صفحه معرفی دارند. مسیر معلم هم فعلاً نمونه اولیه است. وضعیت ادغام برنچ‌ها، محدودیت‌ها و پیشنهادهای بعدی در [گزارش بررسی](docs/REVIEW_FA.md) آمده است.
