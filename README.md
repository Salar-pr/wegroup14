# University Hub

React + TypeScript + Vite frontend starter structure.

## Getting started

1. Install dependencies.
2. Copy `.env.example` to `.env` and configure `VITE_API_BASE_URL`.
3. Run the development server.

Feature code belongs in `src/features/<feature-name>`. Keep reusable,
feature-agnostic UI in `src/components`.

This archive provides the folder scaffold and starter files; it is not yet
a fully configured, installable Vite application.
